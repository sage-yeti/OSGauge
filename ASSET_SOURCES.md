# OS identity icons

The small GIF files in `assets/os_logos/` are original, simplified compatibility identity marks generated for this application. They are not copies of vendor artwork and are not intended to replace official logos. The color associations are used only as visual cues; all product and project names remain the property of their respective owners.

The registry is keyed by the repository's existing `os_family` values and uses `generic-os.ppm` for unknown or missing entries. The icon loader is optional and keeps the textual OS name as the authoritative identifier.
